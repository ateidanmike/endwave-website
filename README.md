# Endwave — Wholesale Internet Capacity

Website for **Endwave NextGen Worldwide**, a wholesale internet capacity provider serving Kenya, Uganda and Tanzania.

Built with plain HTML, CSS and JavaScript. No build step required.

## Structure

```
index.html      Page markup
styles.css      Styles and animations
script.js       Interactions
assets/         Logos and brand mark
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Works on any static host (GitHub Pages, Netlify, Vercel, cPanel). For GitHub Pages: Settings → Pages → Deploy from branch `main`, root folder.
